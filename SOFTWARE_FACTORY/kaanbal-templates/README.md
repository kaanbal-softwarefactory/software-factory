# kaanbal-templates

Catálogo de plantillas desplegables para Kaanbal Console.

- `catalog.json` — índice de plantillas (v4)
- `templates/<category>/<id>/` — scaffold de código, Dockerfile y manifiestos k8s

Backends incluidos: FastAPI y Laravel 13 + React/Inertia.

Publicado por el instalador Kaanbal en la org de GitHub del cliente.
